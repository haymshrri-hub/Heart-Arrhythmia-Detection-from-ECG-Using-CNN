# Heart-Arrhythmia-Detection-from-ECG-Using-CNN
ECG Heart Arrhythmia Detection using 1D-CNN is a deep learning project that classifies ECG heartbeats into five categories: Normal, Supraventricular, Ventricular, Fusion, and Other beats. Using a Kaggle dataset, the model learns waveform patterns and evaluates performance through accuracy, precision, recall, F1-score, and a confusion matrix.
